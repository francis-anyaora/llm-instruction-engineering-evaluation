# System Instruction Engineering & LLM Evaluation

A practical portfolio documenting experience in system instruction design, prompt refinement, and large language model (LLM) response evaluation, drawing on the development of a retrieval-augmented generation legal application.

## Overview

This portfolio demonstrates practical experience designing and refining system instructions to guide model behaviour in an application with diverse user queries and demanding response requirements.

The work involved translating application requirements into structured instructions, managing different query expectations, establishing knowledge-grounding constraints, and refining response behaviour to achieve consistent and relevant outputs.

It also demonstrates an understanding of evaluating model responses against defined quality and compliance criteria.

## Core Capabilities

- **System Instruction Design:** Developing structured instructions that define model roles, behavioural expectations, operational boundaries, and response requirements.
- **Prompt Refinement:** Identifying ambiguities, adjusting instruction wording, resolving competing requirements, and refining prompts to achieve desired outcomes.
- **Knowledge Grounding:** Designing instructions that prioritize retrieved knowledge sources and discourage unsupported claims beyond the available evidence.
- **Dynamic Query Handling:** Accommodating different user intents and task requirements while maintaining consistent application behaviour.
- **Response Formatting:** Establishing requirements for response structure, terminology, citations, and user-facing presentation.
- **LLM Response Evaluation:** Assessing generated responses for instruction following, factuality, accuracy, relevance, completeness, and overall quality.
- **Iterative Improvement:** Using observed model behaviour and evaluation findings to guide instruction refinement.

## Practical Application

The experience documented here draws on the development of a retrieval-augmented generation legal information application.

The application handled questions involving statutory provisions, judicial decisions, legal principles, and legal research. Its system instructions had to accommodate varying query requirements while maintaining appropriate knowledge-source constraints and response standards.

This presented practical challenges involving instruction precision, knowledge grounding, response consistency, source presentation, and model behaviour.

## LLM Evaluation Framework

Model responses can be assessed across several dimensions:

| Evaluation Dimension | Assessment Focus |
|---|---|
| Instruction Following | Compliance with applicable system instructions and task requirements. |
| Factuality | Whether claims are supported by available evidence. |
| Accuracy | Correctness of the information and conclusions presented. |
| Relevance | Alignment with the user's actual query and intent. |
| Completeness | Whether the response adequately addresses the task. |
| Response Quality | Clarity, coherence, and appropriate presentation. |
| Format Compliance | Adherence to prescribed response structures and formatting requirements. |
| Source Grounding | Whether claims are adequately supported by retrieved information. |
